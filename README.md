### 02. IntelliInsight
**Automated Research Paper Intelligence**

> An academic PDF analysis application that generates classification tags, extracts keywords, and produces structured summaries.

<table>
  <tr>
    <td width="58%" valign="top">

**The challenge**

Manually categorizing academic papers and extracting useful concepts from lengthy PDF documents can be time-consuming.

**The approach**

A document-processing workflow that extracts PDF content, applies machine-learning techniques, and returns structured classification results.

**Implementation highlights**
- TF-IDF, Logistic Regression, and BERT embeddings for classification workflows.
- FastAPI microservice for Python-based processing and inference.
- Node.js API layer connected to a React frontend.
